Контекст: Блоки 1-3 выполнены — бот анализирует текст через LLM. Теперь нужно сохранять анализы в БД, чтобы данные не терялись при перезапуске. Стек: SQLAlchemy 2.x async + aiosqlite + Alembic. Правила — в .cursorrules (раздел 5: Database Rules).

Задачи:

3. Реализуй app/database/models/analysis.py — модель Analysis: user_id (FK → User), user_message (Text), bot_response (Text), llm_provider, llm_model, tokens_used (Integer), created_at. Связь User ↔ Analysis (one-to-many)
4. Реализуй app/database/engine.py — create_async_engine(settings.DATABASE_URL), async_sessionmaker, async функция create_tables() для создания таблиц при первом запуске

6. Реализуй app/database/repositories/analysis.py — AnalysisRepository: create(session, ...), get_by_user(session, user_id, limit, offset), count_by_user(session, user_id)
7. Реализуй app/middlewares/database.py — middleware, создающий AsyncSession для каждого запроса, передающий через data["session"], закрывающий после обработки
8. Обнови app/handlers/analyze.py — после анализа сохранять user_message + bot_response в БД, при первом сообщении — get_or_create пользователя
9. Обнови main.py — вызов create_tables() при старте бота
10. Настрой Alembic: обнови migrations/env.py для работы с async engine и моделями, создай первую миграцию

Задачи:
1. Реализуй app/services/pattern_tracker.py — загрузка всех анализов пользователя, подсчёт упоминаний каждого из 5 паттернов в ответах LLM (по ключевым словам/маркерам), формирование сводки: частота, тренды
2. Обнови app/database/models/analysis.py — добавь поле detected_patterns (Text/JSON, nullable) для хранения списка найденных паттернов. Создай Alembic-миграцию для нового поля
3. Обнови app/services/analysis.py или app/handlers/analyze.py — после анализа парсить ответ LLM и заполнять detected_patterns
4. Реализуй app/handlers/patterns.py — хендлер /patterns: показать сводку "Ваши паттерны за N анализов:", визуализация текстом (███░░ Подмена причины — 3 раза). Если мало данных (< 3 анализов) → "Нужно больше анализов для выявления паттернов"
5. Обнови app/bot.py — подключи patterns_router

Проверка: 5+ анализов → /patterns → сводка с визуализацией частоты каждого паттерна.
