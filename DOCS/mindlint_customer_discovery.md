# MindLint: Скрипт Customer Discovery

## Цель интервью

Проверить гипотезу: **люди готовы платить за инструмент, который проверяет логику их решений** (не даёт советы, не мотивирует, а именно аудит).

**Важно:** Не продавать, не убеждать. Слушать и фиксировать.

---

## Целевые респонденты (10-15 человек)

- Фаундеры на ранней стадии
- Продакт-менеджеры / тимлиды
- Фрилансеры, принимающие решения самостоятельно
- Люди, которые уже платят за коучинг или терапию

**Где искать:** Telegram-чаты фаундеров, Indie Hackers, Product Hunt community, LinkedIn.

---

## Структура интервью (25-30 минут)

### Часть 1: Разогрев (3-5 мин)

```
«Спасибо, что согласился. Я исследую, как люди принимают сложные решения. 
Это не продажа — мне важно понять твой опыт. Можно записать?»
```

**Вопросы:**
- Чем занимаешься сейчас?
- Какие решения приходится принимать чаще всего — рабочие или личные?

---

### Часть 2: Проблема (10-12 мин)

**Открывающий вопрос:**
```
«Вспомни последнее решение, которое далось тяжело — 
где ты долго думал(а), сомневался(ась), откладывал(а). Расскажи.»
```

**Углубляющие вопросы:**
- Что именно было сложным? (недостаток информации? страх? неопределённость?)
- Сколько времени ушло на это решение?
- С кем ты это обсуждал(а)? Помогло?
- Как в итоге принял(а) решение?
- Доволен(на) результатом?

**Ключевой вопрос:**
```
«Бывало ли, что ты понимал(а) задним числом: 
"я сам(а) себя обманывал(а), придумывал(а) причины"?»
```

**Если да:** Как понял(а)? Что помогло увидеть это?

**Фиксируй:**
- [ ] Конкретные примеры (записать дословно)
- [ ] Эмоции при описании
- [ ] Сколько времени/денег потеряно из-за плохих решений

---

### Часть 3: Существующие решения (5-7 мин)

**Вопросы:**
- Когда нужно принять сложное решение, что ты делаешь? (друзья? коуч? ChatGPT? ничего?)
- Платишь ли за что-то, что помогает думать? (коучинг, терапия, приложения)
- Пробовал(а) обсуждать решения с ChatGPT/Claude? Как опыт?

**Если использует ChatGPT:**
```
«Что именно просишь? Советы? Анализ? Просто выговориться?»
«Чего не хватает в этом опыте?»
```

**Фиксируй:**
- [ ] Текущие решения и их стоимость
- [ ] Что не устраивает в текущих решениях
- [ ] Сколько платит за коучинг/терапию (если да)

---

### Часть 4: Тест концепции (5-7 мин)

**Не описывай продукт. Опиши сценарий:**

```
«Представь инструмент, который работает так:
ты пишешь своё решение или сомнение,
он раскладывает твою логику на части,
показывает, где всё ок, а где не хватает данных или условие размыто.
Не даёт советов, не мотивирует — только проверяет логику.
Может сказать: "твоя логика нормальная, проблем нет".»
```

**Вопросы:**
- Как бы ты это использовал(а)?
- В каких ситуациях это было бы полезно?
- Чего тут не хватает?

**Критический вопрос:**
```
«Если бы это стоило $10/месяц — подписался бы?»
```

**Варианты ответов и как реагировать:**

| Ответ | Что это значит | Следующий вопрос |
|-------|----------------|------------------|
| «Да, конечно» | Возможно, вежливость | «Почему? Для чего конкретно?» |
| «Может быть» | Нет сильной боли | «Что должно измениться, чтобы точно да?» |
| «Нет» | Честный ответ | «Что не так? Цена или сама идея?» |
| «Я бы попробовал бесплатно» | Нет готовности платить | «А за какую функцию заплатил бы?» |

---

### Часть 5: Закрытие (2-3 мин)

```
«Спасибо, это очень помогло. 

Если я сделаю рабочую версию — можно будет тебе показать? 
Буду рад честной обратной связи.»
```

**Собери:**
- [ ] Email/Telegram для follow-up
- [ ] Разрешение на повторный контакт

---

## После интервью: что фиксировать

### Обязательные метрики

| Метрика | Значение |
|---------|----------|
| Респондент # | |
| Дата | |
| Есть ли проблема с решениями? | Да / Нет / Частично |
| Текущее решение | |
| Платит за решение сейчас? | $ / месяц |
| Готов платить за MindLint? | Да / Может быть / Нет |
| Названная цена | $ |
| NPS (рекомендовал бы?) | 1-10 |

### Качественные данные

- **Дословные цитаты** (самое ценное)
- **Конкретные примеры решений** (для будущего маркетинга)
- **Возражения** (что смущает в концепции)

---

## Критерии успеха валидации

После 10-15 интервью:

| Сигнал | Значит |
|--------|--------|
| 7+ из 10 сказали «да, заплачу» | Сильный сигнал, делать MVP |
| 4-6 из 10 | Слабый сигнал, нужно pivot или уточнение |
| 0-3 из 10 | Проблема не подтверждена, не делать |

---

## Красные флаги (когда не верить)

- «Классная идея!» без конкретики
- «Я бы точно купил» от друзей/знакомых
- Респондент не смог вспомнить ни одного сложного решения
- Все ответы короткие, без эмоций

## Шаблон заметок

```
Респондент: [имя/псевдоним]
Дата: 
Профиль: 

## Проблема
[что рассказал о сложных решениях]

## Текущие решения
[что использует сейчас, сколько платит]

## Реакция на концепцию
[дословно]

## Готовность платить
[да/нет, почему]

## Ключевые цитаты
- "..."
- "..."

## Мой вывод
[что понял из этого интервью]
```

## Частые ошибки

1. **Продавать вместо слушать** — респондент должен говорить 80% времени
2. **Наводящие вопросы** — «Тебе же нужен такой инструмент, да?»
3. **Описывать продукт до вопросов о проблеме** — сначала боль, потом решение
4. **Интервьюировать только друзей** — они не скажут правду
5. **Не записывать дословно** — потом забудешь контекст
