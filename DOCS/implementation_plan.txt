==============================================================
  MindLint — План реализации Telegram-бота
  Python + aiogram 3.x | SQLite | OpenAI + Anthropic + Groq
==============================================================

КОНТЕКСТ
--------
MindLint — AI-инструмент логического анализа решений.
Пользователь пишет утверждение/решение → бот анализирует
логическую структуру через LLM и возвращает разбор:
- Декомпозиция на факты, причины, условия, выводы
- Поиск паттернов: подмена причины, ложная необходимость,
  циклическая логика, неопределённое условие, универсальное оправдание
- Без советов, психологии и оценки личности

==============================================================
LLM-ПРОВАЙДЕРЫ
==============================================================

Используется Strategy Pattern с абстрактным классом и фабрикой.
Переключение — одна переменная LLM_PROVIDER в .env.

┌─────────────┬───────────────┬──────────────┬──────────────────────────┐
│ Провайдер   │ SDK           │ Бесплатный?  │ Модель по умолчанию      │
├─────────────┼───────────────┼──────────────┼──────────────────────────┤
│ Groq        │ groq          │ ДА           │ llama-3.3-70b-versatile  │
│ Anthropic   │ anthropic     │ Нет          │ claude-sonnet-4-20250514 │
│ OpenAI      │ openai        │ Нет          │ gpt-4o                   │
└─────────────┴───────────────┴──────────────┴──────────────────────────┘

GROQ (бесплатный):
  - 30 запросов/мин, 14 400 запросов/день
  - Регистрация без кредитной карты: console.groq.com
  - Модели: Llama 3.3 70B, Llama 3.1 8B, Mixtral 8x7B, Gemma 2 9B
  - Очень быстрый инференс (LPU)
  - SDK интерфейс идентичен OpenAI

Рекомендация:
  - Разработка/тестирование → LLM_PROVIDER=groq (бесплатно)
  - Продакшен → LLM_PROVIDER=anthropic или openai


==============================================================
АРХИТЕКТУРНЫЕ РЕШЕНИЯ
==============================================================

1. ПОРЯДОК РОУТЕРОВ (важен!)
   1) start_router    — /start, /help
   2) admin_router    — /stats, /broadcast (фильтр IsAdmin)
   3) journal_router  — /journal
   4) patterns_router — /patterns
   5) settings_router — /settings
   6) analyze_router  — ПОСЛЕДНИЙ (catch-all для текста)

2. КОНФИГУРАЦИЯ
   - pydantic-settings загружает .env с типизацией
   - Валидация при старте: ошибки сразу видны
   - Admin IDs из конфига, не хардкод

3. ПРОМПТ
   - Отдельный файл app/prompts/system_prompt.txt
   - Извлекается из DOCS/mindlint_system_prompt.md
   - Легко версионировать и редактировать

4. FSM
   - aiogram FSM для многошаговых диалогов
   - Состояния: ожидание утверждения → уточнение → результат
   - MemoryStorage (для SQLite-бота достаточно)

5. БАЗА ДАННЫХ
   - SQLite + aiosqlite (async)
   - SQLAlchemy ORM + Repository pattern
   - Alembic миграции с первого дня

6. MIDDLEWARE
   - database.py: инъекция сессии в хендлеры
   - throttling.py: rate limiting (защита от перерасхода API)
   - admin_check.py: проверка прав админа
